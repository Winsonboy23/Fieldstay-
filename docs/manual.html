前台 · 給訂房客戶

HotelBytezz 訂房操作手冊

從找房、訂房到入住前的所有操作，照著步驟做即可完成。

關於本手冊

本手冊說明客戶端網站的所有功能。每個章節對應一個實際情境，建議第一次使用時依序閱讀；之後可從左側目錄直接跳到需要的章節。

📱

支援裝置

手機、平板、桌機皆可使用，建議使用最新版 Chrome / Safari。

🔐

登入方式

Email 註冊或 Google 一鍵登入，兩者可擇一使用。

01 · 註冊與登入

首次使用請先建立帳號，之後預訂房間、查看訂單都需要先登入。

[ 截圖：登入頁 / 註冊頁 ]
  1. 進入登入頁點右上角「登入」按鈕
  2. 選擇登入方式Google 登入（最快）或使用 Email + 密碼
  3. 驗證 Email（僅 Email 註冊需要）系統會寄一封驗證信，點信中連結即可完成
小提示：Google 登入不需要記密碼，且自動帶入姓名與 Email。

02 · 瀏覽房型

首頁可看到所有房型，包含照片、容納人數、定價與簡介。

[ 截圖：房型列表頁 + 房型詳情頁 ]
  1. 選擇日期與人數點選入住與退房日期，輸入入住人數
  2. 瀏覽房型卡片點任一房型可看完整介紹、設施、價格
  3. 確認後點「立即預訂」

03 · 建立預約

系統會帶你進入訂房表單，填寫入住資料即可。

  1. 確認日期與房型頁面上方會顯示預訂摘要
  2. 填寫個資姓名、電話、Email（已登入會自動帶入）
  3. 填寫特殊需求（選填）例如：嬰兒床、過敏需求、晚到時間等
  4. 確認金額並送出
注意：送出後訂單狀態為「未付款」，需在 24 小時內完成付款，否則系統會自動釋出房間。

04 · 付款與確認

[ 截圖：付款頁 / 訂單成立確認 ]

（依實際金流整合方式撰寫，例如綠界、信用卡、轉帳等。）

05 · 查看我的訂單

點右上角頭像 → 「我的訂單」可看到所有過去與未來的訂單。

  1. 進入會員中心右上角頭像 → 我的訂單
  2. 切換分頁「即將入住」 / 「歷史訂單」
  3. 點任一訂單查看明細

06 · 修改 / 取消預約

在訂單明細頁可以修改特殊需求或取消訂單。

取消政策：入住前 7 天可全額退款，3-7 天退 50%，3 天內不退款。

07 · 編輯個人資料

會員中心 → 個人資料，可修改姓名、電話、預設特殊需求等。

08 · 活動報名

首頁「活動」分頁顯示近期民宿活動。點任一活動可看詳情與報名表單。

09 · 常見問題

找不到驗證信怎麼辦？

請檢查垃圾信件夾，或回到登入頁點「重寄驗證信」。

可以幫家人代訂嗎？

可以，請在「入住人姓名」填寫實際入住者姓名。

HotelBytezz 後台操作 SOP

每日訂單管理、入住退房、房型維護的標準流程。新進員工請從第 01 章開始閱讀。

系統簡介

後台用於管理訂單、入住退房、房型與客戶資料。所有功能依角色權限開放。

📊

Dashboard

每日工作首頁，顯示當日入住 / 退房 / 待處理事項。

📅

Bookings

訂單的核心模組，所有查詢、編輯、入退房都從這裡開始。

🛏️

Rooms

房型、定價、開放日期的設定。

👥

Guests

客戶資料與訂房歷史。

01 · 登入後台

[ 截圖：後台登入頁 ]
  1. 開啟後台網址由主管提供，建議加入瀏覽器書籤
  2. 輸入帳號密碼首次登入會強制改密碼
  3. 進入 Dashboard
安全提醒：請勿與他人共用帳號。離開電腦時務必登出，或使用 ⌘ + L 鎖定螢幕。

02 · 每日工作首頁

每天上班第一件事：打開 Dashboard，確認當日工作。

[ 截圖：Dashboard 全景 ]
  1. 檢查當日入住名單確認房間是否已整理完畢
  2. 檢查當日退房名單10:00 前完成 check-out 提醒
  3. 查看訂單統計卡本日 / 本週 / 本月 訂單數、入住率

03 · 查詢與篩選訂單

左側選單「Bookings」進入訂單列表。

  1. 使用篩選器狀態（未入住 / 入住中 / 已退房 / 已取消）、日期區間
  2. 使用排序依入住日、建立時間、金額排序
  3. 搜尋客戶姓名或訂單編號

04 · 訂單明細與編輯

點任一訂單進入明細頁，可修改入住資訊、特殊需求、付款狀態等。

修改記錄：所有編輯都會記錄修改人與時間，請放心操作。

05 · Check-in 入住作業

[ 截圖：Check-in 流程 ]
  1. 找到該訂單從「今日入住」清單或搜尋姓名
  2. 核對證件身分證 / 護照與訂單姓名一致
  3. 確認付款狀態若為現場付款，先收款再 check-in
  4. 點「Check-in」按鈕狀態變為「入住中」
  5. 交付鑰匙 / 房卡並告知注意事項

06 · Check-out 退房作業

  1. 檢查房間狀況請房務確認無損壞、無遺留物
  2. 結算額外費用若有加購、賠償等
  3. 點「Check-out」按鈕
  4. 通知房務開始整理

07 · 房型管理

新增 / 編輯房型、設定價格、上傳照片、調整可訂日期。

08 · 客戶資料

查看客戶歷史訂房、消費總額、特殊需求備註。VIP 客戶可加註標籤。

09 · 活動管理

建立民宿活動、設定報名人數上限、查看報名名單。

10 · 系統設定

民宿基本資料、營業時間、取消政策、Email 範本等。

11 · 員工帳號

新增員工帳號、設定角色權限（管理員 / 櫃台 / 房務）。

權限說明：只有管理員可新增 / 停用員工帳號。

12 · 疑難排解

客戶說已付款但系統顯示未付款？

請至「訂單明細 → 付款記錄」確認，或聯絡會計核對銀行帳。

訂單狀態卡住改不了？

請通知系統管理員，並提供訂單編號。
